# GitHubで学ぶ中学受験｜予習シリーズ × ChatGPT × Python

**中学受験の教育費を、生成AIとオープンソースで抑えてみませんか？**

本プロジェクトは、四谷大塚の予習シリーズとChatGPT・Pythonを活用し、中学受験の算数・理科を効率的に学ぶための無料オープンソース（Open Source）プロジェクトです。

生徒様・保護者様・塾講師様に向けて、AIによる問題解説、効率的な計算方法、Pythonによる検算、GitHubの使い方を紹介します。

教育コストの削減（Cost Reduction）と学習体験価値（Learning Experience Value）の向上を目指します。

## 1. 予習シリーズとは？

予習シリーズは、四谷大塚が開発した中学受験向け教材です。

小学4〜6年生を中心に、算数・国語・理科・社会を体系的に学習できます。

本プロジェクトでは、特に算数と理科の計算分野を扱います。

| 教科 | 主な学習内容 |
|---|---|
| 算数 | 四則計算、割合、比、速さ、図形、特殊算 |
| 理科 | てこ、ばね、電流、熱量、密度、水溶液 |

## 2. ChatGPTとは？

ChatGPTは、OpenAIが提供する対話型の生成AI（Generative AI）です。

中学受験では、算数・理科の問題を写真で撮影して質問したり、計算方法を比較したり、苦手な単元の類題を作成したりできます。

| お困りごと | ChatGPTによる解決方法 |
|---|---|
| 問題の解き方がわからない | 小学生向けに段階的に解説 |
| 計算に時間がかかる | 約分や分配法則などの工夫を提案 |
| 特殊算が理解できない | 面積図・線分図などで説明 |
| 理科の公式を覚えられない | 公式の意味と単位を解説 |
| 計算ミスが多い | Pythonによる検算 |
| 練習問題が足りない | オリジナルの類題を生成 |
| 自分で考える力をつけたい | 答えを伏せてヒントを提示 |

ChatGPTには、Pythonを利用した数値計算・グラフ作成・データ分析機能もあります。

ただし、すべての回答で自動的にPythonが実行されるわけではありません。

## 4. 教育費削減のシミュレーション

小学5年生が予習シリーズの算数・理科とChatGPTを1年間利用する場合を考えます。

ChatGPTは月額3,000円、個別指導は1回5,000円と仮定します。

### 教材とAIの年間費用

| 項目 | 年間費用 |
|---|---:|
| 予習シリーズ算数 | 4,400円 |
| 予習シリーズ理科 | 4,400円 |
| ChatGPT（月3,000円） | 36,000円 |
| GitHub・Python・Google Colabの無料利用 | 0円 |
| **合計** | **44,800円** |

### 個別指導との比較

| 学習方法 | 年間費用 |
|---|---:|
| 個別指導（月4回） | 240,000円 |
| 予習シリーズ＋ChatGPT | 44,800円 |
| 差額 | **195,200円** |

個別指導を月4回から月2回に減らした場合は、次のようになります。

| 項目 | 年間費用 |
|---|---:|
| 個別指導（月2回） | 120,000円 |
| 予習シリーズ＋ChatGPT | 44,800円 |
| 合計 | 164,800円 |
| 従来の個別指導月4回との差額 | **75,200円** |

AIによって個別指導の利用回数を減らせれば、教育費削減につながる可能性があります。

ただし、これらは仮定に基づく比較であり、実際の削減額や学習効果を保証するものではありません。現在の教材費や家庭の学習環境も考慮する必要があります。

## 5. ChatGPTで予習シリーズの問題を写真から解説する

### スマートフォンでの使い方

1. ChatGPTを開く。
2. 入力欄のプラスボタンから写真を追加する。
3. 予習シリーズの問題を撮影する。
4. 問題文・数値・図形が正しく読み取れているか確認する。
5. 中学受験向けの解法を指定して質問する。

### プロンプト① 中学受験算数の解説

```text
あなたは中学受験専門の算数講師です。

添付した写真の問題を解説してください。

【条件】
・小学4〜6年生が理解できる説明にする
・中学受験算数の解法を優先する
・原則として方程式や高校数学は使わない
・最初に問題文と条件を確認する
・式の意味を一つずつ説明する
・計算結果を検算する
・間違えやすいポイントを説明する
```

### プロンプト② より速く正確な計算方法を考える

```text
この問題を中学受験算数の方法で解いてください。

【比較する内容】
1. 基本的な解法
2. 工夫した解法
3. 計算量が少ない解法
4. ミスを防ぐポイント

約分、分配法則、結合法則、
比や割合などを必要に応じて活用してください。

最後に、試験時間を考慮して
最もおすすめの解法を説明してください。
```

### プロンプト③ 特殊算で解く

```text
あなたは中学受験の算数講師です。

この問題を小学6年生までに学ぶ
特殊算を使って解説してください。

必要に応じて以下の方法を検討してください。

・つるかめ算
・植木算
・旅人算
・通過算
・仕事算
・割合と比
・面積図
・線分図
・ダイヤグラム

なぜその解法が適切なのか説明してください。

無理に特殊算を当てはめず、
最も理解しやすい方法を優先してください。
```

### プロンプト④ 理科の計算問題

```text
あなたは中学受験専門の理科講師です。

添付した写真の問題を解説してください。

【条件】
・小学生が理解できる方法を使う
・公式の意味を説明する
・単位を必ず確認する
・比例、反比例、比を活用する
・計算過程を省略しない
・答えが現実的か確認する

てこ、ばね、電流、熱量、密度、
水溶液などの単元に応じて、
適切な考え方を説明してください。
```

### プロンプト⑤ 答えを教えずヒントを出す

```text
あなたは中学受験の家庭教師です。

答えをすぐに教えず、
ヒントを一つずつ出してください。

最初は考え方だけを説明し、
私が回答したら次のヒントを出してください。

間違えた場合も、
すぐに正解を教えるのではなく、
どこで考え違いをしたのか質問してください。
```

### プロンプト⑥ Pythonで計算結果を検算する

```text
この問題を中学受験算数の方法で解説してください。

その後、Pythonを使って計算結果を検算してください。

【条件】
・小学生向けの解法を優先する
・Pythonは検算のために使用する
・問題文の数値と条件を確認する
・計算結果が一致しない場合は原因を調べる
・Pythonを実行できない場合は明記する
```

### プロンプト⑦ オリジナルの類題を作る

```text
あなたは中学受験の教材作成者です。

この問題と同じ考え方を使う
オリジナルの類題を3問作成してください。

【条件】
・基礎、標準、応用の3段階にする
・小学4〜6年生の範囲で作成する
・答えが成立する条件を確認する
・Pythonで検算できる場合は実行する
・問題と解答・解説を分けて表示する
```

## 7. GitHubとは？初心者向けの使い方

GitHubは、ソースコードや学習資料を保存・公開し、変更履歴を管理できるサービスです。

本プロジェクトでは、Pythonの計算ツール、ChatGPTのプロンプト、算数・理科の学習資料を無料公開するために利用します。

### GitHubの基本用語

| 用語 | 意味 | 本プロジェクトでの用途 |
|---|---|---|
| Repository | ファイルの保管場所 | 教材・プログラムを公開 |
| README.md | プロジェクトの説明書 | 学習方法を紹介 |
| Commit | 変更履歴の記録 | 解説やコードの修正を管理 |
| Branch | 作業を分ける機能 | 新しい教材を開発 |
| Issue | 課題管理 | 改善要望を記録 |
| Pull Request | 変更内容の提案 | 教材の改善を共同で進める |
| Release | バージョンの公開 | 動作確認済みツールを配布 |
| License | 利用条件 | OSSの利用条件を明示 |

### GitHubの使い方を学べるおすすめサイト

| サイト | 学べる内容 | 言語 |
|---|---|---|
| [GitHub公式クイックスタート](https://docs.github.com/ja/repositories/creating-and-managing-repositories/quickstart-for-repositories) | リポジトリ作成、ファイル管理 | 日本語 |
| [GitHub公式READMEガイド](https://docs.github.com/ja/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) | README.mdの作成と編集 | 日本語 |
| [サル先生のGit入門](https://git-tutorial.backlog.com/) | Gitの基礎、コミット、ブランチ | 日本語 |
| [GitHub Skills](https://skills.github.com/) | GitHubの操作を実践形式で学習 | 英語 |
| [Introduction to GitHub](https://github.com/skills/introduction-to-github) | Commit、Branch、Pull Request | 英語 |
| [GitHub Docs](https://docs.github.com/ja) | GitHubの機能全般 | 日本語 |

### GitHubで最初にやること

1. [GitHub](https://github.com/)で無料アカウントを作成する。
2. `chuugaku-juken-ai` というリポジトリを作成する。
3. README.mdにプロジェクトの説明を記載する。
4. 算数・理科のプロンプトをMarkdownファイルで保存する。
5. Pythonの計算ツールをアップロードする。
6. Commitで変更履歴を記録する。
7. Issuesで改善課題を管理する。

最初はブラウザだけで操作できます。Gitのコマンドをすべて覚える必要はありません。

## 8. Python・Google Colab・Jupyter Notebookとは？

### Python

Pythonは、計算処理・データ分析・AI開発などに利用されるプログラミング言語です。

本プロジェクトでは、算数・理科の計算問題を生成し、答えを検証するために使用します。

### Google Colab

Google Colabは、ブラウザからPythonを実行できるサービスです。

基本的な利用は無料で、Pythonをパソコンにインストールしなくても学習を始められます。

### Jupyter Notebook

Jupyter Notebookは、Pythonのコード、説明文、計算結果、グラフを一つのファイルにまとめられる実行環境です。

## 9. 安全な利用と著作権

- ChatGPTの回答には誤りが含まれる場合があります。
- AIは塾講師による指導を完全に代替するものではありません。
- 問題を撮影する際は、氏名・学校名などの個人情報を含めないでください。
- 自作ソフトウェアと独自作成教材をオープンソースとして公開します。
- AIサービスの利用料と教材の購入費は、無料公開するソフトウェアとは別です。

本プロジェクトは非公式の個人開発活動であり、四谷大塚とは関係ありません。

## 10. プロジェクトの理念

**中学受験を、もっと安く、もっと効率的に、もっと自由に。**

予習シリーズとAIドリブン開発を融合し、中学受験の計算学習課題を解決します。

オープンソース文化の普及を推進し、生徒様・保護者様・塾講師様に寄り添いながら、課題発見から開発・運用改善までアジャイルに伴走する教育特化型SIerを目指します。
