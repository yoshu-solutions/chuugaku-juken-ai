
## GitHubで学ぶ中学受験｜予習シリーズ × ChatGPT × Python

**中学受験の教育費を、生成AIとオープンソースで抑えてみませんか？**

本プロジェクトは、四谷大塚の予習シリーズとChatGPT・Pythonを活用し、中学受験の算数・理科を効率的に学ぶための無料オープンソース（Open Source）プロジェクトです。

生徒様・保護者様・塾講師様に向けて、GitHubの使い方、AIドリブン開発（AI-Driven Development）、計算問題の解説・検算方法を日本語と英語で紹介します。

教育コストの削減（Cost Reduction）と学習体験価値（Learning Experience Value）の向上を目指します。

---

## 1. 予習シリーズとは？

予習シリーズは、四谷大塚が開発した中学受験向けの教材です。

小学4〜6年生を中心に、算数・国語・理科・社会を体系的に学習できます。

特に算数・理科では、基本的な知識から応用問題まで段階的に学べます。

本プロジェクトでは、算数の計算・割合・速さ・図形と、理科の電流・てこ・ばね・水溶液などの計算分野を中心に扱います。

## 2. ChatGPTとは？

ChatGPTは、OpenAIが提供する対話型の生成AI（Generative AI）です。

中学受験では、次のような用途に活用できます。

| お困りごと | ChatGPTによる解決方法 |
|---|---|
| 算数の解き方がわからない | 解法を段階的に解説 |
| 計算が複雑 | 工夫した計算方法を提案 |
| 理科の公式が理解できない | 公式の意味と単位を説明 |
| 類題が足りない | オリジナル問題を生成 |
| 計算ミスが多い | Pythonによる検算 |
| 質問する相手がいない | ヒント形式で学習を支援 |
| 苦手分野がわからない | 学習履歴・誤答傾向を分析 |

最近のChatGPTには、Pythonを利用した数値計算・グラフ作成・データ分析機能もあります。

ただし、すべての回答で自動的にPythonが実行されるわけではありません。

## 4. 教育費はどれくらい削減できる？

小学5年生が予習シリーズの算数・理科とChatGPTを1年間利用する場合を考えます。

ChatGPTの費用は月額3,000円と仮定します。

### 教材とAIの年間費用

| 項目 | 年間費用 |
|---|---:|
| 予習シリーズ算数 | 4,400円 |
| 予習シリーズ理科 | 4,400円 |
| ChatGPT（月3,000円） | 36,000円 |
| GitHub・Python・Google Colabの無料利用 | 0円 |
| **合計** | **44,800円** |

年間約4.5万円で、教材とAI学習支援環境を用意できる試算です。

### 個別指導との比較

個別指導を1回5,000円、月4回利用する家庭を想定します。

| 学習方法 | 年間費用 |
|---|---:|
| 個別指導（月4回） | 240,000円 |
| 予習シリーズ＋ChatGPT | 44,800円 |
| 差額 | **195,200円** |

すべての個別指導を置き換えられる場合、年間約19.5万円の費用差が生まれます。

ただし、AIが講師と同等の指導を提供できるとは限りません。

より現実的に、個別指導を月4回から月2回に減らした場合は次のようになります。

| 項目 | 年間費用 |
|---|---:|
| 個別指導（月2回） | 120,000円 |
| 予習シリーズ＋ChatGPT | 44,800円 |
| 合計 | 164,800円 |
| 従来の個別指導月4回との差額 | **75,200円** |

このモデルでは、年間約7.5万円の費用削減となります。

※ いずれも仮定に基づく試算です。個別指導費には教材費を含めていないため、実際の比較では現在の教材費も考慮する必要があります。

## 5. ChatGPTで予習シリーズの問題を写真から解説する

### スマートフォンでの使い方

1. ChatGPTを開く。
2. 入力欄のプラスボタンから写真を追加する。
3. 予習シリーズの算数・理科の問題を撮影する。
4. 問題文・数値・図形が正しく読み取れているか確認する。
5. 中学受験向けの解法を指定して質問する。

### プロンプト① 中学受験の算数講師として解説

```text
あなたは中学受験専門の算数講師です。

添付した写真の問題を解説してください。

【条件】
・小学4〜6年生が理解できる説明にする
・中学受験算数の解法を優先する
・原則として方程式や高校数学は使わない
・最初に問題文と条件を確認する
・式の意味を一つずつ説明する
・計算結果を検算する
・間違えやすいポイントを説明する

予習シリーズの学習範囲を意識して、
わかりやすく解説してください。
```

### プロンプト② より速く正確な計算方法を考える

```text
この問題を中学受験算数の方法で解いてください。

【比較する内容】
1. 基本的な解法
2. 工夫した解法
3. 計算量が少ない解法
4. ミスを防ぐポイント

約分、分配法則、結合法則、
比や割合などを必要に応じて活用してください。

最後に、試験時間を考慮して
最もおすすめの解法を説明してください。
```

### プロンプト③ 特殊算を使って解く

```text
あなたは中学受験の算数講師です。

この問題を小学6年生までに学ぶ
特殊算を使って解説してください。

必要に応じて以下の方法を検討してください。

・つるかめ算
・植木算
・旅人算
・通過算
・仕事算
・割合と比
・面積図
・線分図
・ダイヤグラム

なぜその解法が適切なのか説明してください。

無理に特殊算を当てはめず、
最も理解しやすい方法を優先してください。
```

### プロンプト④ 理科の計算問題を解説

```text
あなたは中学受験専門の理科講師です。

添付した写真の問題を解説してください。

【条件】
・小学生が理解できる方法を使う
・公式の意味を説明する
・単位を必ず確認する
・比例、反比例、比を活用する
・計算過程を省略しない
・答えが現実的か確認する

てこ、ばね、電流、熱量、密度、
水溶液などの単元に応じて、
適切な考え方を説明してください。
```

### プロンプト⑤ 答えを教えずヒントを出す

```text
あなたは中学受験の家庭教師です。

答えをすぐに教えず、
ヒントを一つずつ出してください。

最初は考え方だけを説明し、
私が回答したら次のヒントを出してください。

間違えた場合も、
すぐに正解を教えるのではなく、
どこで考え違いをしたのか
質問してください。
```

### プロンプト⑥ Pythonで計算結果を検算する

```text
この問題を中学受験算数の方法で解説してください。

その後、Pythonを使って計算結果を検算してください。

【条件】
・小学生向けの解法を優先する
・Pythonは検算のために使用する
・問題文の数値と条件を確認する
・計算結果が一致しない場合は原因を調べる
・Pythonを実行できない場合は明記する
```

### プロンプト⑦ 間違えた問題の類題を作る

```text
あなたは中学受験の教材作成者です。

この問題と同じ考え方を使う
オリジナルの類題を3問作成してください。

【条件】
・基礎、標準、応用の3段階にする
・小学4〜6年生の範囲で作成する
・答えが成立する条件を確認する
・Pythonで検算できる場合は実行する
・問題と解答・解説を分けて表示する
```

## 7. GitHub・Python・Jupyter Notebookの使い方

本プロジェクトでは、IT初心者の方でも無料ツールを活用できるように解説します。

### GitHubとは？

GitHubは、ソースコードや学習資料を保存・公開し、変更履歴を管理できるサービスです。

### 基本用語

| 用語 | 意味 |
|---|---|
| Repository | ファイルやコードの保管場所 |
| README.md | プロジェクトの説明書 |
| Commit | 変更履歴を記録する操作 |
| Issue | 課題や改善案の管理 |
| Pull Request | 修正内容の確認・提案 |
| Release | 動作確認済みバージョンの公開 |
| License | ソフトウェアの利用条件 |

### Pythonとは？

Pythonは、計算処理・データ分析・AI開発などに利用されるプログラミング言語です。

本プロジェクトでは、計算問題の生成、答えの検証、学習履歴の分析などに使用します。

### Google Colab・Jupyter Notebookとは？

Pythonのコードと説明文を組み合わせて学習できる実行環境です。

特にGoogle Colabは、ブラウザから利用でき、基本的なPython学習を無料で始められます。

- [GitHub](https://github.com/)
- [Python公式サイト](https://www.python.org/)
- [Google Colab](https://colab.research.google.com/)
- [Jupyter公式サイト](https://jupyter.org/)

## 9. 安全な利用と著作権

- ChatGPTの回答には誤りが含まれる場合があります。
- AIによる解説は、必ずしも塾講師の指導を代替するものではありません。
- 問題を撮影する際は、氏名・学校名などの個人情報を含めないでください。
- 自作ソフトウェアと独自作成教材をオープンソースとして公開します。
- AIサービスの利用料と教材の購入費は、無料公開するソフトウェアとは別です。

本プロジェクトは非公式の個人開発活動であり、四谷大塚とは関係ありません。

## 10. プロジェクトの理念

**中学受験を、もっと安く、もっと効率的に、もっと自由に。**

予習シリーズとAIドリブン開発を融合し、中学受験の計算学習課題を解決します。

オープンソース文化の普及を推進し、生徒様・保護者様・塾講師様に寄り添いながら、課題発見から開発・運用改善までアジャイルに伴走する教育特化型SIerを目指します。
